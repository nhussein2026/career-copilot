# LinkedIn profile checklist

Walk every item. For each fail, name the exact offending element so the fix is actionable. Recruiters skim top-to-bottom in seconds and LinkedIn's search ranks on keyword match + completeness + activity — a profile can be honest and still be invisible.

## 1. First impression (the top card)

- [ ] Professional profile photo — head-and-shoulders, face ~60% of frame, plain/neutral background, recent
- [ ] Custom background banner (not the default gray) — simple, on-brand, no clutter behind the photo/text overlay
- [ ] Custom vanity URL: `linkedin.com/in/firstname-lastname` (not the default `/in/firstname-1a2b3c4d`)
- [ ] Location set to the metro area you want to be recruited in (not a tiny suburb search misses)
- [ ] "Open to work" set if job-seeking (recruiter-only visibility is available if you don't want it public)

## 2. Headline (the highest-leverage field)

- [ ] Not just the current job title — includes role + specialization + value or key skills
- [ ] Front-loads the most searchable keyword (the target job title) in the first ~40 characters
- [ ] Uses real, honest role language; no buzzword salad ("ninja", "guru", "rockstar")
- [ ] Reads well on mobile where it's truncated — the important words come first
- [ ] Uses the full length usefully (up to 220 characters) without keyword stuffing

## 3. About / summary

- [ ] First 2–3 lines hook before the "…see more" fold (this is all most viewers read)
- [ ] Written in first person, in the candidate's voice — not a third-person bio, not a copy of the resume summary
- [ ] Names the target role, core skills, and what the person is known for / wants to do next
- [ ] Includes a light call to action or contact preference at the end
- [ ] Keyword-rich but natural; hard skills appear as plain words search can match

## 4. Experience

- [ ] Every relevant role present, reverse-chronological, with correct company (linked to the real company page) and dates
- [ ] Each role has a one-line scope/context statement + 2–4 impact bullets (action verb + what + measurable outcome)
- [ ] Bullets match the resume's claims — no contradictions in title, dates, or scope
- [ ] Media/links attached where they add proof (a demo, a talk, an article) — optional but strong
- [ ] No unexplained multi-year gaps; short contract/freelance work is labeled honestly

## 5. Skills & endorsements

- [ ] At least 5 skills listed; ideally the platform max, all genuinely held
- [ ] Top 3 skills pinned and aligned to the target role (these show first and are weighted in search)
- [ ] Skills mirror the exact terms used in target job descriptions (string match matters)
- [ ] No "expert"-level framing contradicted by experience level

## 6. Education, certifications, projects

- [ ] Education present with correct institution and dates
- [ ] Licenses & Certifications section used for real credentials, with issuer and date (and credential URL if available)
- [ ] Projects/portfolio linked where relevant; links actually resolve

## 7. Credibility & activity

- [ ] At least 2–3 recommendations from managers, peers, or clients (quality over quantity)
- [ ] 500+ connections OR a clearly growing, relevant network (the counter caps display at "500+")
- [ ] Some recent activity — posts, comments, or reshares in the last ~30 days (active profiles rank and surface better)
- [ ] Contact info section filled (email at minimum; portfolio/GitHub where relevant)

## 8. Consistency & hygiene

- [ ] Name, current title, and dates match the resume exactly
- [ ] No typos in the Headline, About, or company/role names
- [ ] Technology names spelled/capitalized correctly (JavaScript, TypeScript, Node.js, PostgreSQL, React)
- [ ] One consistent professional identity across the profile (no leftover old-career headline in the banner text)
