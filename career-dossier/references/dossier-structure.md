# Dossier structure

The dossier is a superset of a resume: everything real, organized so any AI or tool can pull exactly what it needs. Keep headings predictable and formatting consistent. Tag facts with their source in parentheses — `(CV)`, `(GitHub: repo)`, `(LinkedIn)`, `(portfolio)`, `(confirmed)` — so downstream uses can trust and trace each claim.

## Layout

```
# <Full Name> — Career Dossier
_Last updated: <date>. Source of truth; every item tagged with its origin._

## Identity & contact
- Name, location (+ willing-to-relocate/remote), email, phone
- LinkedIn, GitHub, portfolio, other profiles (all verified working)

## Positioning
- 2–4 honest angles this person could credibly target (e.g. "Full-stack (React/Node)", "Frontend specialist")
- One-line value statement for each angle, grounded in the evidence below

## Skills (with depth + evidence)
- Group: Languages / Frontend / Backend / Databases / Tools / AI / Practices
- For each skill: honest level + where it's demonstrated (which project/role) — not a bare list

## Work history (complete)
- Every role: title, company, location, dates
- Full bullets (action + what + scope + outcome), not the curated resume subset
- Scope facts: team size, ownership, what they decided vs. implemented

## Projects (all real)
- Per project: name + links (repo + live, verified), stack, what it does, the candidate's role, what it proves
- Note team vs. solo; mark tutorial-grade honestly

## Open-source contributions
- Merged work in repos the candidate does NOT own, with links (kept separate from self-projects)

## Education / Certifications / Languages
- As held, with dates and issuers; honest language levels

## Links
- Every verified URL in one place

## Facts & metrics bank
- A flat list of every real number and outcome: users, requests, commit counts, %
  improvements, team sizes, durations. The reusable raw material for quantified bullets.

## Gaps & to-confirm
- Missing metrics as [confirm: …]
- Unverified items and cross-source conflicts still open
- Honest weak spots (e.g. a required skill not yet held)
```

## Rules
- **Comprehensive, not curated** — include everything real; curation happens later in the resume/letter. But still exclude fabrications and clearly-not-theirs forks.
- **Source-tagged** — every fact shows its origin; that traceability is the dossier's whole value.
- **Honest depth** — skill levels and project complexity match the evidence; no inflation.
- **Machine-friendly** — consistent headings, one fact per line where practical, so any AI can map it into other formats.
