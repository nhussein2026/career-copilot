# Certifications by field

A guide to which certifications actually carry weight, by field, and when a cert is worth the time and money versus when it's a distraction. Use it to give honest advice — never recommend a cert just to have something to recommend.

## When a certification is worth it

A cert earns its cost when at least one is true:
- **It's a hiring filter** — postings list it as required/preferred and screeners actually gate on it (common in cloud, security, networking, PM, and regulated fields).
- **It's a vendor or regulatory requirement** — you can't do or sell the work without it (e.g. some cloud partner tiers, safety/finance/health compliance).
- **It's a credible signal for a career-changer** — you lack on-the-job proof and the cert plus a project demonstrates baseline competence.

## When a certification is NOT worth it

- For most **software engineering** roles: shipped projects, open-source contributions, and a strong GitHub outweigh certificates. A generic "full-stack certificate" rarely moves a hiring decision.
- When it substitutes for proof of work you could build instead — a real project usually beats a course completion badge.
- Expensive certs pursued before you know the target role wants them. Check live job postings first.
- Endless course-collecting ("tutorial hell") with no shipped work to show for it.

## Software Engineering / Web

- **Honest verdict:** portfolio and contributions dominate; certs are optional. Skip generic bootcamp completion certs as your headline credential.
- **If useful:** cloud certs below (deployment is a real gap for many devs); a well-known course *only* as a learning path, not a résumé centerpiece.

## Cloud & DevOps (certs matter here)

- **AWS:** Cloud Practitioner (entry) → Solutions Architect Associate / Developer Associate → Professional / specialty (Security, Networking).
- **Microsoft Azure:** AZ-900 (Fundamentals) → AZ-104 (Administrator) / AZ-204 (Developer) → AZ-305 (Solutions Architect Expert).
- **Google Cloud:** Associate Cloud Engineer → Professional Cloud Architect / Professional Data Engineer.
- **Kubernetes:** CKA (Administrator), CKAD (Application Developer), CKS (Security).
- **HashiCorp:** Terraform Associate.

## Data / ML / AI

- **Data engineering:** cloud data certs (GCP Professional Data Engineer, Azure DP-203, AWS Data Analytics); Databricks certifications.
- **Data analytics/BI:** Google Data Analytics (entry credibility for career-changers), Microsoft PL-300 (Power BI), Tableau Desktop Specialist/Certified.
- **ML/AI:** vendor ML certs (AWS ML Specialty, Azure AI Engineer AI-102, TensorFlow Developer). Verdict: for research/applied ML roles, published work, competitions, and projects outweigh certs; for cloud-ML platform roles, vendor certs help.

## Cybersecurity (certs matter a lot here)

- **Entry:** CompTIA Security+ (baseline, widely required, incl. some gov/defense roles), CompTIA Network+ as a precursor.
- **Mid:** CEH (offensive-awareness, HR-recognized), CySA+, GIAC tracks (GSEC, GCIH).
- **Offensive/hands-on:** OSCP (highly respected, practical exam), practical GIAC certs.
- **Senior/management:** CISSP (5-year experience requirement; a hiring filter for senior security roles), CISM, CISA.
- **Cloud security:** the cloud providers' security specialty certs.

## Networking & IT / Systems

- CompTIA A+ / Network+ / Security+ (IT support and help-desk ladders often gate on these).
- Cisco: CCNA → CCNP (still valued in network engineering).
- Microsoft/Linux: relevant Azure/AWS admin certs; LPIC / Red Hat RHCSA & RHCE for Linux.

## Project / Product Management

- **Project management:** PMP (the standard for experienced PMs; requires documented hours), CAPM (entry), PRINCE2 (common in UK/EU), PMI-ACP or the Scrum credentials (CSM, PSM I/II) for agile roles.
- **Product management:** certs are weak signals — real product outcomes, shipped features, and case studies dominate. Optional: reputable PM courses for structured learning, not as a credential.

## Design (UX/UI)

- **Honest verdict:** portfolio is everything; certs are near-irrelevant to hiring. A Google UX Design certificate can help an absolute beginner build a first portfolio and vocabulary — treat it as a learning path, not a credential. Accessibility (IAAP CPACC/WAS) can matter for specialist roles.

## Finance / Accounting / Business

- Genuinely credential-driven: CPA (accounting), CFA (investment/finance), FRM (risk), CMA (management accounting), ACCA/CIMA (UK/Commonwealth). Here the certification often *is* the qualification, not a supplement.

## Marketing

- Platform certs are cheap credibility, not differentiators: Google Ads, Google Analytics (GA4), Meta Blueprint, HubSpot (inbound, content). Useful for entry-level and freelancers; a strong campaign/portfolio matters more at senior levels.

## How to advise with this file

1. Pull the person's target field and current level.
2. Check whether their target job postings actually list a cert as required/preferred.
3. Recommend the *earliest* cert that unblocks them, plus a project that proves the same skill.
4. Say plainly when a cert is a distraction and a shipped project would serve them better.
